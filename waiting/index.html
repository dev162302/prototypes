NOTES

Everything except Ripple Ascent is a single self-contained HTML file with no dependencies — drop it anywhere and it runs. Ripple Ascent is a React + Vite build with the game engine kept framework-agnostic, so it can be lifted into any stack. Scores are stored on the device only; no accounts, no tracking, no data leaves the phone. Logo and colours follow the brand guide; Apis is standing in as Source Sans 3 until the licensed font pack arrives, so nothing here is a final brand asset.
