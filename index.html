Warps for demos. Add to any RIPPLE link: #run=1 jumps straight into a Daily Run, #board=1 opens the leaderboard, #stage=3&x=1500 drops you at a chosen point in a stage. PULSE takes ?play=1 to skip the intro.

The lower three sections are the parallel set — built portrait-first, so hold the phone upright for those. All single-file except RIPPLE ASCENT, which is a React + Vite build with the game engine kept framework-agnostic. Scores are stored on the device only; no accounts, no tracking.

Still placeholders. Logo, exact brand blues and the typeface are all standing in until the guidelines pack arrives. Nothing here is an official brand asset.
